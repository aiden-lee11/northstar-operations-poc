Key decisions

Why I chose a feature-flag demo

Given the assessment’s two-hour build allowance, I chose a bounded feature-flag workflow rather than an end-to-end KYC system. Even a realistic KYC review queue would involve sensitive evidence, verification providers, reviewer permissions, decision records and retention. Recreating its screen would understate the engineering work required to integrate and maintain it.

For this client, I would reserve from-scratch AI-assisted rebuilds for lightweight tools with manageable integration and maintenance needs. Working production tools should remain in place unless a specific bottleneck justifies replacing them. Devin can accelerate development, but engineers still own support, incidents and changing integrations. Those hours compete with product work.

The feature-flag example lets an operator change a rollout, see its effect on synthetic customers, and roll back. I chose it because the limited workflow is observable and testable without recreating several dependent systems. It illustrates a tool the team could consider owning, not proof that a production flag platform is lightweight or that future maintenance will be cheap.

Architecture and tradeoffs

The React/TypeScript UI calls one Python server, which holds flag configuration, evaluation and change history in a shared store. The backend uses stable account buckets to choose which checkout each test account sees. Changes require a reason and a version check; rollback records a new change instead of deleting history. The baseline was built locally with Devin, and the evaluator and customer preview were implemented through Devin Cloud.

This is a small local demo and is nowhere near production-ready. Data is synthetic, held in memory and lost on restart. There is no authentication, durable audit storage or production deployment setup. It has not been connected to or tested against real external APIs, and it does not demonstrate regulatory compliance. Those integrations and security requirements would need separate engineering and review before real use.
